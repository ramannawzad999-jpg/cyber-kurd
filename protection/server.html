🛡️ Server Protection

فێربە چۆن سێرڤەرەکەت بپارێزیت لە هێرش و مەترسییەکانی تۆڕ.

1. Cloudflare Protection

Cloudflare یارمەتیت دەدات ترافیکی گومانلێکراو فلتەر بکەیت و پاراستنی DDoS بەکاربهێنیت.

ئەرک: چالاککردنی DNS و Proxy و Security Settings.

ماڵپەڕی Cloudflare

2. Firewall

Firewall ڕێگە بە ترافیکی ناپەسەند نادات بگاتە سێرڤەرەکەت.

ئامانج: تەنها پۆرت و خزمەتگوزارییە پێویستەکان بکەرەوە.

3. Rate Limiting

سنووردارکردنی ژمارەی داواکارییەکان لە ماوەیەکی دیاریکراودا بۆ کەمکردنەوەی بەکارهێنانی خراپ.

4. HTTPS و SSL

HTTPS پەیوەندی نێوان سەردانکەر و ماڵپەڕەکەت پارێزراوتر دەکات.

5. Backup

لە فایل و داتاکانی سێرڤەرەکەت بە شێوەی بەردەوام کۆپی پارێزراو هەڵبگرە.

6. Security Checklist

  • پاشکۆد و وشەی نهێنیی بەهێز بەکاربهێنە.
  • سیستەم و پەکێجەکان نوێ بکەرەوە.
  • پۆرتە ناپێویستەکان دابخە.
  • Log ـەکان بەردەوام بپشکنە.
  • هەژماری بەڕێوەبەر بە MFA بپارێزە.
