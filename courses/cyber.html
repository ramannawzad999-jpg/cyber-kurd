📘 وانەی ١: Ethical Hacking چییە؟

Ethical Hacking واتە تاقیکردنەوەی ئاسایشی کۆمپیوتەر و تۆڕ بە مۆڵەتی خاوەنەکەی، بۆ دۆزینەوە و چاککردنەوەی کێشە ئەمنییەکان.

⚖️ وانەی ٢: یاسا و ڕێوشوێن

  • پێش تاقیکردنەوە مۆڵەتی ڕوون وەرگرە.
  • تەنها لەسەر سیستەمی خۆت یان لابراتواری ڕێگەپێدراو کار بکە.
  • هیچ زانیارییەکی کەسی مەدزە.
  • هەموو هەنگاوەکان تۆمار بکە.
  • کێشە ئەمنییەکان بە شێوەیەکی بەرپرسانە ڕاپۆرت بکە.

🌐 وانەی ٣: Network Security

تۆڕ چییە؟

تۆڕ کۆمەڵێک ئامێرە کە پەیوەندییان بەیەکەوە هەیە بۆ گواستنەوەی زانیاری.

چەند زاراوەی گرنگ:

  • IP Address: ناونیشانی ئامێر لە تۆڕدا.
  • DNS: گۆڕینی ناوی دۆمەین بۆ IP.
  • Router: ئامێری بەڕێوەبردنی پەیوەندیی تۆڕ.
  • Firewall: سیستەمی کۆنترۆڵکردنی هاتووچۆی تۆڕ.
  • HTTPS: پەیوەندیی پارێزراو لەگەڵ ماڵپەڕ.

🐧 وانەی ٤: Linux Basics

بینینی ناوی بەکارهێنەر:

whoami

بینینی شوێنی ئێستا:

pwd

بینینی فایلەکان:

ls -la

🔐 وانەی ٥: Password Security

وشەی نهێنیی پارێزراو دەبێت:

  • درێژ و تایبەت بێت.
  • بۆ هەر هەژمارێک جیاواز بێت.
  • لە شوێنی پارێزراودا هەڵبگیرێت.
  • دوو هەنگاوی پشتڕاستکردنەوە (2FA) چالاک بکرێت.

🌍 وانەی ٦: Web Security

چەند مەترسییەکی باوی ماڵپەڕ:

  • SQL Injection
  • Cross-Site Scripting (XSS)
  • Broken Authentication
  • Security Misconfiguration

ئەم بابەتانە لە ژینگەی فێرکاری و بە نموونەی پارێزراو فێر دەبین، بۆ ئەوەی بتوانیت ماڵپەڕەکان بپارێزیت.

🔎 وانەی ٧: Digital Forensics

Digital Forensics بریتییە لە کۆکردنەوە و لێکۆڵینەوەی بەڵگە دیجیتاڵییەکان بە شێوەیەکی یاسایی و پارێزراو.

🏆 وانەی ٨: CTF Challenges

CTF یارییەکی فێرکارییە کە تێیدا کێشە ئەمنییەکان لە ژینگەیەکی تایبەت و ڕێگەپێدراودا چارەسەر دەکرێن.
