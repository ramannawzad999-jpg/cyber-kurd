🐙 GITHUB ACADEMY

فێربوونی Git و GitHub بە زمانی کوردی

🏠 گەڕانەوە بۆ سەرەتا

١. Git چییە؟

Git ئامرازێکە بۆ تۆمارکردنی گۆڕانکارییەکانی کۆد و گەڕانەوە بۆ وەشانی پێشوو.

٢. GitHub چییە؟

GitHub پلاتفۆرمێکە بۆ هەڵگرتن و هاوبەشکردنی پرۆژەکانی کۆد لەسەر ئینتەرنێت.

٣. دامەزراندنی Git

pkg update
pkg install git

٤. پشتڕاستکردنەوەی دامەزراندن

git --version

٥. ڕێکخستنی ناو و ئیمەیڵ

ناوی خۆت لە شوێنی Your Name دابنێ:

git config --global user.name "Your Name"

ئیمەیڵی خۆت لە شوێنی your@email.com دابنێ:

git config --global user.email "your@email.com"

٦. دروستکردنی Repository

بچۆ GitHub و هەژمارێک دروست بکە، پاشان New Repository هەڵبژێرە.

ناوی پرۆژەکەت دابنێ و Create Repository بکە.

٧. ئامادەکردنی پرۆژەی خۆت

mkdir my-project
cd my-project
git init

٨. تۆمارکردنی گۆڕانکارییەکان

git status
git add .
git commit -m "First commit"

٩. پەیوەستکردن بە GitHub

لە شوێنی URL لینکی Repository ـی خۆت دابنێ:

git remote add origin YOUR_REPOSITORY_URL
git branch -M main
git push -u origin main

١٠. گرنگیی پاراستنی هەژمار

  • وشەی نهێنیی خۆت بە کەس مەدە.
  • Personal Access Token وەک وشەی نهێنی بپارێزە.
  • 2FA چالاک بکە.
  • API Key و زانیاریی نهێنی لە Repository ـی گشتی دابنێ مەکە.

١١. تاقیکردنەوە

کام فەرمان گۆڕانکارییەکان تۆمار دەکات؟
