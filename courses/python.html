١. Python چییە؟

Python زمانێکی پرۆگرامسازییە کە بۆ دروستکردنی ماڵپەڕ، بەرنامە، شیکردنەوەی داتا و ئامرازەکانی پاراستنی سایبەری بەکاردێت.

٢. یەکەم بەرنامە

نووسینی Hello World:

print("Hello World")

ئەنجام:

Hello World

٣. گۆڕاوەکان (Variables)

گۆڕاو شوێنێکە بۆ هەڵگرتنی زانیاری.

name = "Kurdistan"
age = 20

print(name)
print(age)

٤. جۆرەکانی داتا

name = "Raman"
age = 18
price = 12.5
active = True

print(type(name))
print(type(age))
print(type(price))
print(type(active))

٥. مەرجەکان (If / Else)

age = 18

if age >= 18:
    print("Adult")
else:
    print("Young")

٦. دووبارەکردنەوە (Loops)

for number in range(1, 6):
    print(number)

٧. فەنکشن (Functions)

def greeting(name):
    print("Hello", name)

greeting("Friend")

٨. لیست (Lists)

tools = ["Python", "Linux", "Git"]

for tool in tools:
    print(tool)

٩. پرۆژەی بچووک: ژمێرەر

first = float(input("First number: "))
second = float(input("Second number: "))

print("Sum:", first + second)
print("Difference:", first - second)
print("Product:", first * second)

if second != 0:
    print("Division:", first / second)
else:
    print("Cannot divide by zero")
