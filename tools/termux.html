📱 فێربوونی Termux

فەرمانە سەرەتاییەکانی Termux بە زمانی کوردی

🏠 گەڕانەوە بۆ سەرەتا

١. نوێکردنەوەی Termux

بۆ نوێکردنەوەی پاکەتەکان:

pkg update && pkg upgrade

٢. دامەزراندنی ئامرازەکان

دامەزراندنی Python و Git و Nano:

pkg install python git nano

٣. فەرمانە بنەڕەتییەکان

بینینی شوێنی ئێستا:

pwd

بینینی فایلەکان:

ls

پاککردنەوەی شاشە:

clear

دروستکردنی فۆڵدەر:

mkdir myfolder

چوونە ناو فۆڵدەر:

cd myfolder

دروستکردنی فایل:

touch file.txt

٤. زانیاریی سیستەم

وەشانی Python:

python --version

وەشانی Git:

git --version

ناوی بەکارهێنەر:

whoami

٥. گرنگیی پاراستن

هەمیشە تەنها لەسەر ئامێر و تۆڕێک کار بکە کە خاوەندارێتی یان مۆڵەتی تاقیکردنەوەی هەیە.

فەرمانەکان پێش جێبەجێکردن بخوێنەوە و تێبگە.
