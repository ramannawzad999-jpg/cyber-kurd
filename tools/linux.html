🐧 LINUX ACADEMY

فێربوونی Linux بە زمانی کوردی

🏠 گەڕانەوە بۆ سەرەتا

١. Linux چییە؟

Linux سیستەمێکی کارپێکردنە کە لە کۆمپیوتەر، سێرڤەر و ئامێرە جۆراوجۆرەکان بەکاردێت.

٢. فەرمانە بنەڕەتییەکان

بینینی شوێنی ئێستا:

pwd

بینینی فایل و فۆڵدەرەکان:

ls -la

دروستکردنی فۆڵدەر:

mkdir learning

دروستکردنی فایل:

touch notes.txt

خوێندنەوەی ناوەڕۆکی فایل:

cat notes.txt

پاککردنەوەی شاشە:

clear

٣. بەڕێوەبردنی پاکەتەکان

نوێکردنەوەی پاکەتەکان لە Debian:

sudo apt update

دامەزراندنی Python:

sudo apt install python3

بینینی وەشانی Python:

python3 --version

٤. زانیاریی سیستەم

زانیاریی وەشانی Linux:

uname -a

بینینی کاتی سیستەم:

date

بینینی بۆشایی دیسک:

df -h

بینینی بەکارهێنانی بیرگە:

free -h

٥. پاراستنی Linux

  • سیستەمەکەت بەردەوام نوێ بکەرەوە.
  • فەرمانێکی نەناسراو بەبێ تێگەیشتن جێبەجێ مەکە.
  • وشەی نهێنیی بەهێز بەکاربهێنە.
  • فایلە گرنگەکانت پاشەکەوت بکە.
  • ئاگاداری فەرمانەکانی سڕینەوە بە.

٦. تاقیکردنەوەی خۆت

کام فەرمان شوێنی ئێستات پیشان دەدات؟
