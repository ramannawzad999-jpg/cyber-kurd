🌐 ئامرازەکانی تۆڕ

فێربوونی بنەماکانی تۆڕ و پاراستنی ئینتەرنێت

🏠 گەڕانەوە بۆ سەرەتا

١. زانینی IP ـی ئامێر

بۆ بینینی IP ـی ناوخۆیی مۆبایل:

ip addr

٢. تاقیکردنەوەی ئینتەرنێت

بۆ تاقیکردنەوەی پەیوەندی ئینتەرنێت:

ping -c 4 1.1.1.1

٣. زانیاریی DNS

بۆ بینینی زانیاریی DNS:

cat $PREFIX/etc/resolv.conf

٤. دامەزراندنی ئامرازەکانی تۆڕ

دامەزراندنی curl و wget:

pkg install curl wget

دامەزراندنی DNS utilities:

pkg install dnsutils

٥. زانینی زانیاریی دۆمەین

بۆ نموونە، زانیاریی دۆمەینی example.com ببینە:

nslookup example.com

٦. بنەماکانی پاراستنی تۆڕ

  • وشەی نهێنیی بەهێز بەکاربهێنە.
  • ڕاوتەرەکەت بەردەوام نوێ بکەرەوە.
  • بە لینکە گومانلێکراوەکان مەچۆ.
  • تەنها تۆڕی خۆت یان تۆڕی ڕێگەپێدراو تاقی بکەرەوە.
